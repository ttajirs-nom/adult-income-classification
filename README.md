📌 Adult Income Prediction ML Project
🚀 Project Overview

This is an end-to-end Machine Learning project that predicts whether a person's income is <=50K or >50K based on demographic and work-related features.

It includes:

Model training (scikit-learn)
FastAPI backend
Streamlit frontend
Real-time prediction system

📊 Dataset
Adult Income Dataset (Census data)
Features include:
age, workclass, education, occupation, etc.

🤖 ML Models Used
Logistic Regression
Decision Tree
Support Vector Machine (SVC)
K-Nearest Neighbors (KNN)

✔ Best Model saved as model.pkl

⚙️ Tech Stack
Python
Pandas, NumPy
Scikit-learn
FastAPI
Streamlit
